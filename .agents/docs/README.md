## 🚀 Comment alimenter la base de connaissances

1. Tous les documents doivent être rédigés en format **Markdown (`.md`)**.
2. Organisez les nouveaux documents par domaine fonctionnel ou technique.
3. Ajoutez un lien vers tout nouveau document dans la table ci-dessus dans `README.md`.

---

## 🤖 Directives pour l'IA (Antigravity Agent)

Lors de toute intervention sur le projet **fus-dashboard**, vous devez :
- Consulter les documents pertinents dans `.agents/docs/` avant de proposer de grands changements.
- Mettre à jour la documentation dans `.agents/docs/` lorsque l'architecture, les données ou la logique métier évoluent.
